# JavaScript Toolkit

A lightweight JavaScript toolkit for building web applications and utilities.

## About

This repository contains reusable JavaScript tools, examples, and utilities for frontend and backend development.

## Features

- Terminal emulator for both browser console, serial, and backend
- JSON formatting tool
- Base64 encoding and decoding tool

## Getting Started

1. Clone the repository `git clone https://github.com/T-MuangT/javascript-toolkit.git`
2. `npm install && npm start`
